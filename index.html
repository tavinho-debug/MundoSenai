Módulos do Curso

Uma trilha de aprendizagem completa, indo desde a base de programação até algoritmos avançados de Inteligência Artificial.

Linguagem Python

A base da ciência de dados. Lógica de programação, estruturas de dados, orientação a objetos e manipulação de arquivos.

  • Lógica e Sintaxe
  • Bibliotecas Pandas e NumPy
  • Limpeza e Tratamento de Dados

Banco de Dados (SQL)

Onde os dados vivem. Aprenda a modelar, armazenar e realizar consultas complexas em bancos de dados relacionais e NoSQL.

  • Modelagem de Dados
  • Consultas SQL Avançadas
  • PostgreSQL e MongoDB

Análise Exploratória

Estatística aplicada. Compreenda distribuições, tendências, correlações e crie visualizações ricas usando Matplotlib e Seaborn.

  • Estatística Descritiva
  • Visualização de Dados (Gráficos)
  • Identificação de Outliers (Anomalias)

Machine Learning

Crie modelos preditivos. Ensine máquinas a aprender padrões usando algoritmos de classificação, regressão e clusterização.

  • Scikit-Learn
  • Modelos Supervisionados
  • Redes Neurais Básicas

Power BI e BI

Apresentação de resultados. Crie dashboards interativos e profissionais para contar histórias com dados e embasar decisões de negócios.

  • DAX e ETL no Power BI
  • Dashboards Interativos
  • Data Storytelling

Projeto TCC prático

Desenvolva uma solução fim a fim para um problema real da indústria como seu trabalho de conclusão.
